# Capstone Project: SafeShare v.2 - Secure Event-Driven File Vault

## Overview
SafeShare v.2 is a production-ready, secure file sharing platform. Users can register, enable MFA, upload files, get shareable expiring links. Architecture v.2 adds Event-Driven security automation: S3 -> EventBridge -> Lambda for virus scanning, thumbnail generation, and audit logging. Designed to showcase all bootcamp skills with cost < $25 for 5 days.

Demo URL: https://safeshare-v2.example.com
Project Name: ce-capstone-safeshare-v2

## Architecture v.2 - Event-Driven

### Core Flow
User -> CloudFront (HTTPS) -> ALB -> ECS Fargate (Node.js API) -> RDS (PostgreSQL)
Upload Flow: React -> S3 Presigned URL -> S3 Bucket -> S3 Event -> EventBridge -> Lambda (Scanner, Thumbnailer, Metadata Writer)

### Components
- Frontend: React + S3 + CloudFront + WAF + ACM (HTTPS)
- Backend: Node.js + Express (Dockerized) + ECS Fargate (3 tasks min, Service Auto Scaling up to 6)
- Database: RDS PostgreSQL t3.micro (Multi-AZ) Encrypted + ElastiCache Redis t3.micro (presigned URL cache)
- Storage: S3 (Private Bucket, Block Public Access, SSE-S3, Versioning, Access Logging)
- Event-Driven Layer: S3 Event Notifications -> EventBridge (Custom Bus) -> Lambda Functions
  - Lambda-1: FileScan (ClamAV) - Auto-quarantine malicious files
  - Lambda-2: Thumbnailer (Sharp) - Create 200px thumbnail for images
  - Lambda-3: AuditLogger - Write metadata to RDS + CloudWatch Logs
- Network: VPC (10.0.0.0/16) with 2 Public + 2 Private Subnets across 2 AZs (eu-central-1a/b), NAT Gateway, Internet Gateway
- Load Balancing: ALB (HTTPS Listener 443) with Target Group + Health Check /health
- Security: Secrets Manager, IAM Least Privilege, Security Groups
- Monitoring: CloudWatch, CloudTrail, GuardDuty, Security Hub

## User Stories
1. As a user, I can register an account with email verification
2. As a user, I can log in with email/password + TOTP MFA
3. As a user, I can view my dashboard with my files and storage usage (Instance ID, AZ shown)
4. As a user, I can upload a file via presigned S3 URL
5. As a user, I can get a shareable expiring link (15 min)
6. As a user, I can see thumbnail preview if file is image (generated by Lambda)
7. As a user, I can delete my file (S3 + RDS soft delete)
8. As an admin, I can see virus scan results in Security Hub

## Security Requirements (v.2 Enhanced)
- Authentication with MFA (TOTP - Google Authenticator)
- Data encrypted at rest (S3 SSE, RDS Encrypted) and in transit (TLS 1.2+ ALB + CloudFront)
- HTTPS only (ALB Listener 80 redirect to 443)
- Least-privilege IAM roles: ECS Task Role, Lambda Execution Role, No *:* 
- CloudTrail enabled in all regions + S3 Data Events
- VPC Flow Logs + S3 Access Logs enabled
- WAF on ALB + CloudFront (OWASP Top 10 Rules)
- Secrets stored in Secrets Manager (DB credentials, JWT secret) - No hardcoded secrets
- S3 Block Public Access ON + Bucket Policy Deny Unencrypted Uploads
- Lambda code scanning with Trivy
- EventBridge events encrypted
